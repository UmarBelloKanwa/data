
# VTU Site Project

## Overview
This project is a simple **VTU (Virtual Top-Up)** site created during the process of learning CSS. The goal was to practice and improve CSS skills while building a functional and visually appealing web page.

The site is hosted at: [VTU Site](https://umarbellokanwa.github.io/data/data.html) (mobile view)

## Features
- **Simple VTU Interface**: A clean and minimalistic design for a VTU service.
- **CSS Styling**: The site primarily focuses on showcasing CSS skills, with attention to layout, colors, and typography.
- **Responsive Design**: The site adjusts its layout based on the screen size, ensuring usability on both desktop and mobile devices.

## Technologies Used
- **HTML**: Provided the structure of the web page.
- **CSS**: Styled the page with a focus on aesthetics and responsiveness.

## How It Works
1. The site presents a simple interface for a VTU service.
2. CSS is used to style the components and ensure a consistent look across devices.
3. The page is responsive, providing an optimal viewing experience on different screen sizes.

## Lessons Learned
This project helped in:
- Gaining hands-on experience with CSS for styling web pages.
- Understanding the importance of responsive design.
- Practicing how to structure a simple project using HTML and CSS.
